DeepSeek API 不止能聊天：我做了一个开源 AI 工具箱 Deepseek-chat

发表于2026-11-17|更新于2026-11-17
|阅读量:

一、DeepSeek 开放 API，能做什么？

提到 DeepSeek API，很多人的第一反应还是“接一个聊天机器人”。但现在，官方开放的能力已经不止对话和推理，而是一套可以组合使用的应用接口：

  • 对话与推理：支持流式回答，并提供 Messages、Responses、Chat Completions 等接入方式。
  • 搜索与网页阅读：Search 搜索网页，Fetch 获取网页正文，也可以在对话中使用联网搜索和链接阅读。
  • 文件与文字识别：支持文件输入，OCR 可提取图片和文档中的文字。
  • 语音交互：ASR 把音频转成文字，TTS 把文字合成为语音。

这意味着，开发者可以把“搜索资料 → 阅读整理 → 生成回答 → 语音播报”串成一个工作流，而不只是做一个聊天输入框。

DeepSeek 还提供了官方开源项目 chat-demo，展示这些能力如何组合成聊天产品。接入说明见官方构建指南。注意，API 开放不等于免费，使用限制与费用以官方说明为准。

二、我的开源项目：Deepseek-chat

基于官方 chat-demo，我继续扩展了一个轻量客户端 Deepseek-chat，把聊天、搜索、链接阅读、OCR 和语音工具放在同一个工作区里。

它是一个纯前端项目，不需要额外搭建应用后端，浏览器直接请求配置的 API 服务。

以下截图来自当前项目，使用本地演示数据，仅展示界面，不代表真实 API 调用效果。

聊天之外，也能查资料

聊天页面保留了多会话、流式回答、深度思考和智能搜索，支持 Markdown、代码高亮、公式和 Mermaid 图表。

另外增加了独立的 Search 页面，方便直接搜索、查看摘要和翻页；Fetch、OCR 入口则把链接或文件提交到新对话中处理。

音频转文字，文字转音频

ASR 页面支持上传符合格式要求的音频进行转写，结果可以复制，也能导出为 TXT、Markdown 或 JSON。

TTS 页面可以朗读文字，也可以将合成音频下载为 WAV 文件，方便保存和后续使用。

Search、ASR、TTS 各有独立的本地历史记录，支持记录开关与删除确认；界面也支持中英文、深浅色主题和移动端布局。

会话与工具历史保存在浏览器本地，但使用 AI 功能时，相关内容仍会发送给 API 服务。请只在可信页面填写自己的 API Key。

三、开源地址与本地体验

项目采用 MIT 许可证。推荐使用 Node.js 24 和 pnpm 12.6.0，本地启动只需：

打开 http://localhost:8090，在「设置 → 数据管理」中填写自己的 API Key，即可使用接口功能。

如果你也想体验 DeepSeek 的多种 API，或者在 chat-demo 的基础上继续做自己的工具，欢迎看看这个项目。

开源地址：https://github.com/yuchuangu85/Deepseek-chat
